1–5为近侧腿承重、远侧腿前摆；6–10为远侧腿承重、近侧腿前摆。顺序各为接触、下沉、早期回收、经过、预接触。暖亮近侧鞋在近侧抬腿时仍保持前景遮挡，远侧鞋保持稍暗；不靠镜像整个人物替代另一半步态。对应关键诊断为第4帧大鞋支撑、小鞋抬起；第9帧小鞋支撑、大鞋抬起。

整板生成再次重复领步，未选用。改为逐个角色姿势绘制，分别固定承重侧和遮挡后补中间姿势。保留源帧和最终选用提示词；未采用的高抬腿/踢腿姿势不进入交付。主角继续空手，维持白发红眼、皮甲和红披风。
