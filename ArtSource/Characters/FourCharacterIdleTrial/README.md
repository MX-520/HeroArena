## 参考与验证

参考来源、抽样范围、关键姿势与未借用内容见[动作设计与参考](动作设计与参考.md)，生成来源与SHA256见generation-record.json。只学习公开预览的动作机制；没有复用或发布第三方人物图片。

四张生成原板已逐帧静态查看：主角全程空手，第6帧闭眼；三类敌人均保留武器，未出现纯特效代替身体。能看出吸气抬肩/呼气回落及布料、火焰差异；这不是用户视觉验收或游戏背景下的正常速度美术验收。生成过程存在细节/体积漂移：披风/皮带轮廓、握手与武器细节、持斧肩头起伏偏大，需实际大小下继续评审。

技术检查：32张透明帧所有alpha>0像素完整保留、可见RGBA与所属原板区域逐像素一致；四张单PNG各格与独立帧逐像素一致；根锚点按足底16行中点暂定，未按包围框中心追踪躯干。原板存在RGB非零但alpha为零的隐藏背景色，检查合成透明背景正常，保留原alpha。不同角色体高仍需游戏内PPU校准，不代表已统一生产密度。

内部无头浏览器检查32次逐帧定位、前后帧/重置/洋葱皮/剪影控制和每角色超过两次正常速度循环均通过，无脚本错误；该检查仅证明播放功能，不能自动判断美术质量。报告见extraction-report.json、browser-verification.json及各角色technical-report.json。浏览器初次受沙箱启动限制，后在授权隐藏进程下重试通过。
