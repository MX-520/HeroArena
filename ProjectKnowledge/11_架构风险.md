# 风险与待验证事项

这里记录风险与改进建议，不将静态疑点写成已复现 Bug。

| 事项 | 依据/影响 | 跟进方式 |
|---|---|---|
| 旧人物素材授权 | 用户明确说明来源无有效授权，首页曾参考旧角色 | 按 [13](13_素材授权与替换计划.md) 替换并清理引用 |
| 编辑器验证会退出进程 | CompleteDemoVerification.Finish 调用 EditorApplication.Exit | 在专用验证会话执行，先保护交互编辑器工作 |
| 旧 Setup 会改资产 | Assets/Editor 多个迁移入口可打开/保存正式场景 | 调用前读源码，不能将旧 Setup 当健康检查 |
| 导航修复的适用范围 | 石柱问题曾因全局净空调整影响普通障碍 | 保留局部修复，回归柱边和普通障碍两侧 |
| 证据可迁移性 | Logs 通常不入 Git，旧 PASS 未必有本地原文件 | 明确历史结果和本次实测，关键结论保留范围 |
| 配置与说明漂移 | Scene/Variant 覆盖字段默认值；旧文档不断追加 | 当前说明只留现值，旧过程归档，调参核对资产 |

对象池、Addressables、复杂框架等扩展没有当前需求证据，不列为必须重构事项。
