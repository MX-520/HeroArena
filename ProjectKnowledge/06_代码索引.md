## 编辑器入口

| 入口 | 用途 |
|---|---|
| [CharacterArtworkSetup](../Assets/Editor/CharacterArtworkSetup.cs) | 读取玩家实际攻击点、半径、缩放和身体高度；MeasureLive 保留编辑器，Measure 用于独立批处理并退出 |
| [HeroArenaEditorBridge](../Assets/Editor/HeroArenaEditorBridge.cs) | 显式打开正式场景或保存并关闭编辑器；协议见 12 |
| [CompleteDemoVerification](../Assets/Editor/CompleteDemoVerification.cs) 及 partial 文件 | 射击、远程、波次、掉落、UI、导航与音频验证；完成后退出编辑器 |
| [HeroArenaVerification](../Assets/Editor/HeroArenaVerification.cs) | 早期 Runner/波次专项验证 |
| [CompleteDemoSetup](../Assets/Editor/CompleteDemoSetup.cs) 及各 Setup 文件 | 历次配置迁移，运行前检查内容，不能当作无副作用的查询 |
| [CompleteDemoBuild](../Assets/Editor/CompleteDemoBuild.cs) | 旧构建入口，当前不执行打包 |

验证选择与编辑器关闭风险见 [12](12_完整Demo迭代.md)。新增、删除或改名脚本时更新本索引；字段细节直接查看源码。
