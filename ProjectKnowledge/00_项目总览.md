# HeroArena 项目入口

Unity 2022.3 LTS / C# / 2D Action RPG Demo，目标是展示 Unity 客户端开发能力与完整战斗循环。当前可玩版本包含三波挑战，下一阶段重点为替换无有效授权的人物素材。

## 接手顺序

1. 读根目录 [AGENTS.md](../AGENTS.md) 与 [当前状态](01_当前开发状态.md)，确认本次目标和用户最新要求。
2. 用 Git 工作区、实际代码和场景配置核对现状；文档不替代现场证据。
3. 按任务读取下表中的对应资料，无需每次通读历史。
