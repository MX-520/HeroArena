# 森林试炼首页原画

`ForestTrial.png` 是本项目专用的全屏开始界面背景，由内置 imagegen 于 2026-10-17 生成。

参考：本项目 `Logs/demo-hud-wide.png` 的主角、绿色哥布林、森林石圈、石柱及小桥；未使用外部游戏素材作为生成参考。

构图：左侧约四成是暗青森林留白，供 Unity 叠加中文标题和按钮；右侧是红围巾主角、普通/持斧/远程哥布林、金色弹道与紫色能量球。关键角色位于画面中部，允许宽屏裁切上下。原画没有文字，所有文案和交互均由 uGUI 提供。

生成要求：横幅像素插画、森林遗迹、克制魔法高光、近战和射击同时可辨认、左侧低细节留白、不绘制 UI 或文字。按等比铺满显示；原图保留在本目录，未修改已有战斗素材。
