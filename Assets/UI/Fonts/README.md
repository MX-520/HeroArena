# 中文字体

Noto Sans CJK SC Regular，来自 https://github.com/notofonts/noto-cjk ，按随附OFL.txt的SIL Open Font License 1.1使用。

原字体：https://raw.githubusercontent.com/notofonts/noto-cjk/main/Sans/OTF/SimplifiedChinese/NotoSansCJKsc-Regular.otf
许可证：https://raw.githubusercontent.com/notofonts/noto-cjk/main/Sans/LICENSE

HeroArenaChinese SDF.asset为针对当前中文UI和键位/数字生成的静态TMP字形图集，黑色细描边增强透明背景上的可读性。新增文案后运行ChineseUISetup.Apply更新字形。源字体保留以便重建，不依赖玩家系统字体。
