# Unity 工程审查

1. 读项目入口、当前状态和 AGENTS.md；检查版本、包、Git 工作区及任务范围。
2. 用 rg 定位相关源码与调用链，按需追到 Scene、Prefab Variant、Animator、Input、Layer 和导航配置；字段默认值不代表对象现值。
3. 对照资料，区分当前实现、历史计划、静态风险与已复现问题；评估实际影响而非列泛化清单。
4. 输出问题、源码/资产依据、影响与最小验证方法，说明未检查部分。没有运行能力时不能声称通过运行验证。

默认只读；用户同时授权修复或整理时按任务继续，不把审查扩展成全工程重构。
