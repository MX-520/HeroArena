# 工具接口核对

本文件不复制易过期的完整 schema。工具名、动作、枚举、参数结构和返回字段以当前客户端暴露的定义为准。

按目标寻找场景/对象/组件、脚本、资产/Prefab、Console、截图、测试等能力；先查询对象标识与组件数据，再改字段和绑定引用。

隐藏工具可能属于未启用的工具组或 custom tools；只有当前服务提供组管理/自定义工具入口时才进一步检查。不因参考提到某工具就调用不存在的方法。

向量、颜色、布尔值和资产路径按实际 schema 填写，避免猜测自动转换；UI 类型按实际 uGUI/TMP 包核对。

服务文档与运行反馈冲突时保留错误证据，检查版本和实例，缩小操作后验证；不通过反复刷新或升级依赖掩盖问题。
