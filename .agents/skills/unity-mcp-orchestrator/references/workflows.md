# HeroArena 编辑器操作参考

## 查询和打开场景

确认当前工程及未保存场景，查正式 SampleScene 是否已加载；按项目 12 文档选择现有 open-scene 桥接或可用 MCP 操作。桥接 close 会保存全部场景并退出，不用作状态查询。

## 编辑与验证

定位对象/组件 → 检查当前引用与覆盖 → 修改 → 等待导入/编译 → Console → 实际行为/画面 → 相关差异检查。创建和引用依赖按顺序执行，不把所有修改并行发送。

## 自动验证

先读 Assets/Editor 内对应入口和 ProjectKnowledge/12_完整Demo迭代.md。CompleteDemoVerification 完成会退出 Unity；独立验证会话与用户编辑会话分开处理，避免同工程编辑器锁冲突。

## 失败恢复

编译时等待；domain reload 后重新确认连接；对象状态过期时重新查询；只有证据支持时回退本次失败变更，保留用户已有工作。未能执行的验证直接写明。
