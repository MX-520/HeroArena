# HeroArena 变更审查

读取根 AGENTS.md 与相关架构/代码/配置条目；按本次差异选择检查范围，不固定通读全套知识库。

- 伤害：接收层的无敌/护罩是否被绕过，重复命中及致命/非致命事件是否正确。
- 状态/动画：受伤、翻滚、攻击、死亡和禁用的中断/恢复；晚到动画回调不能复活动作或敌人。
- 敌人：EnemyController 决策与 EnemyAttack 执行边界；距离、命中几何和遮挡共同判断攻击。
- 导航/环境：石柱修复局限于四柱；普通障碍绕行、销毁重建、Agent 有效性不能退化。
- 波次/掉落：分组隔离、重复计数、出生失败、死亡触发、保底与整局清理。
- 流程/音频/UI：暂停时间、输入开关、重载、订阅清理、真实成功事件反馈。

输出有证据的问题、影响和对应回归；区分已复现与静态风险。审查请求只输出审查；同时授权修复时继续实施，按 AGENTS.md 交付，不再增加独立审批步骤。
