# Unity Bug 诊断

读相关历史失败方案，但用当前实现和观察建立证据。

1. 区分用户报告和本次复现，记录环境、触发顺序、对象状态与预期。
2. 沿实际链追踪：输入/状态 → 动画及事件 → 物理/导航 → 命中与生命周期；只检查相关部分。
3. 为候选原因设计能支持或排除它的低影响检查，不同时盲改多个参数。
4. 在修复授权内实施最小变更，再验证原复现及相关中断、死亡、暂停和重载；诊断请求只输出诊断。

特别检查：晚到回调、订阅清理、协程停止、子 Collider 重复命中、脚底与导航参考点差异、Prefab 覆盖。不能仅凭禁用某组件推断所有调用都停止。

输出：现象/复现、根因证据、候选原因、修改范围、实际回归和未验证项。修了代码但未回归时记“已调整待验证”，不能记“已解决”。
