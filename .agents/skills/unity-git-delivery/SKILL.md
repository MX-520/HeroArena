# Unity Git 交付

以根 AGENTS.md 的项目约定和当前任务授权为准。

1. 检查 status、分支、近期 log 和相关 diff；识别原有改动，复用合适分支，不为走流程强制切分支。
2. 完成变更及相称验证，只同步有变化的资料。纯文档工作不跑无关 Unity 测试。
3. 检查具体路径、资源/.meta 配对、生成文件、配置及暂存区；按路径暂存，不盲用 add -A。
4. 在本地提交授权内 commit，再核对提交和剩余工作区。当前项目每个稳定功能/独立修复分别保存。

不把 push 当本地提交的默认后续动作；推送、合并、删除分支、覆盖/清理工作需相应授权。仅要求审查或准备方案时不提交。交付说明实际提交、验证及限制，不伪造哈希或结果。
