# Unity 功能设计

从用户预期行为和验收条件出发，先定位已有实现及可复用接口。

- 明确职责边界、数据来源/所有权、配置与运行状态；按规模选择方案，不默认新增管理器或框架。
- 梳理初始化、动作中断、死亡、禁用、重生/重开及清理；事件、协程和动画不能遗漏退出路径。
- 列出实际源码与 Scene/Prefab/Animator/Input/导航影响，说明最小实施顺序与相关验证。
- 涉及资源生成或能力缺口时按项目工具选型流程评估，不将“安装插件”本身当成功能完成。

仅要求设计时交付方案；要求实现时简述设计后直接实施到验证交付。遵守已有授权，不因本 skill 再次等待确认。关键目标不明才澄清。
