# 关键姿势与运动设计

## 空间与时间

在游戏实际尺寸看轮廓；固定相机和地面投影。Q版大头仍需有头胸髋的重量关系。

角色锚点是游戏根位置，不是包围框中心。跳跃/翻滚时不能把离地的脚自动贴回地面。原地行走中，着地脚相对于根向后运动；有世界位移时，两者合成后支撑脚应近似锁在地面。不要在Sprite与Transform重复施加根位移。

时长从玩法推导。固定帧率可重复暴露某原画表达停顿，须区分原画张数与采样帧数。骨骼动画用曲线控制。循环末→首也占一个间隔；不重复首帧造成停顿。

| 动作 | 主运动关系 | 典型失误与修正 |
|---|---|---|
| 待机 | 头腰错相起伏、胸肩呼吸、布料滞后、脚底稳定 | 只动披风、深蹲或过度压小为近乎静止；分开控制幅度/帧数，检查首尾速度 |
| 行走 | 左接触→下沉→经过→抬升→右接触→下沉→经过→抬升 | 只动披风不换重；先髋和脚，再服装 |
| 奔跑 | 推蹬、腾空、落地、压缩，手臂反摆 | 仅加速行走；明确腾空与着地时间 |
| 近战 | 加载重心→髋肩带动→武器加速过命中弧→随动→恢复 | 刀光掩盖瞬移/伸缩；先看握点与刀尖连续轨迹 |
| 施法 | 聚力→指向→释放→反冲/恢复 | 法杖换手、发射方向错；固定持械/发射插槽，弹体独立 |
| 翻滚 | 预压→离地→收身旋转→落地展开→恢复 | 从球形瞬间站起；分清根路径、身体旋转、无敌窗口 |
| 受击 | 冲击方向、胸髋错位、支撑调整后恢复 | 与死亡混杂；明确能否返回待机 |
| 死亡 | 失衡→失去支撑→落地→余动→静止 | 倒地闪回站姿、穿身；非循环终态和武器生命周期 |
| 特效 | 出现→扩张/运动→衰减 | 大小随机、弹体粘在角色；分离发射表现和飞行载体 |

这些是起点；四足/飞行/触手按实际支撑和推进机制设计。

## 原创实例：单次挥剑

仅为设计示例，不覆盖既有Clip。假设朝右、近手持剑、原地单斩，总长0.60秒。

| 时间 | 阶段 | 身体与武器 | 语义 |
|---|---|---|---|
| 0.00 | 进入 | 可承接的警戒姿势 | 开始 |
| 0.10 | 蓄力 | 髋后坐，肩手后上加载，支撑稳定 | 明确预警 |
| 0.20 | 最大蓄力 | 胸髋扭转，刀尖在弧起点 | 不提前命中特效 |
| 0.25 | 挥出 | 髋肩带动手臂，刀尖加速 | 命中窗口候选开始 |
| 0.30 | 通过目标 | 清楚的命中轮廓，允许有意拖影 | 主命中候选 |
| 0.40 | 随动 | 沿同一弧减速，承接惯性 | 窗口候选结束 |
| 0.52 | 收势 | 手臂折回，胸髋归位 | 恢复 |
| 0.60 | 交接 | 回待机/移动或连击入口 | 按现有状态机结束 |

透视缩短不等于装备变形；要在相同透视条件比较。允许受控夸张/拉伸/拖影，但前后姿势应解释得通。

## 生成约束

要求同一动作的连续时间采样，而非八个不同动作。逐帧给骨架/关键姿势，固定相机、服装、持械手、体型与调色板。真实透明、独立等尺寸帧、固定根锚点、足够边距，不把文字标签写入图像。

不带特效先验动作，再加独立特效。冻结优秀帧，只修有问题的帧/肢体。连续两轮同一结构失败时，检查姿势约束或转绑定/手工修帧，不无限重抽整板。
